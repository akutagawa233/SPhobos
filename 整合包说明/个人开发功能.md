# 1.建造前提描述
在 `rulesmd.ini` 之中：
```ini
[SOMETECHNO] ;任意单位
UIPrerequisite= ;单位列表,工具描述上会显示列表上的所有单位
```
在 `uimd.ini` 之中：
```ini
[ToolTips]
PrerequisiteLabel= ;CSF条目,建造前提的标题
PrerequisiteYes=TXT:PrerequisiteYes ;CSF条目,当某条建造前提达到时显示的文字
PrerequisiteNo=TXT:PrerequisiteNo ;CSF条目,当某条建造前提没有达到时显示的文字
```
# 2.单位额外属性
在 `rulesmd.ini` 之中：
```{note}
-这个功能旨在拓展各项单位属性代码,可以更精细更丰富的设置每一个单位的各项属性
-根据ExtrasType不同每个代码对应的效果会不一样，请根据文档注释查看对应ExtrasType的注释
-ExtrasType是必填的，决定这个额外属性类型属于哪一个ini代码
-Efffect.XXX根据ExtrasType的不同会有不同的效果，请查看对应ExtrasType的注释
```

```ini
[ExtrasTypes]            ;额外属性注册表
0=SOMEEXTRASTYPES

[SOMEEXTRASTYPES]
ExtrasType=              ;额外属性的代码,填原版引擎对应功能的属性代码

;以下代码为属性的实现逻辑
Prerequisite.Condition=  ; 决定额外建造条件以什么方式实现
;以下为效果定义
Effect.Technos=          ; 单位列表
Effect.Weapons=          ; 武器列表
Effect.Warheads=         ; 弹头列表
Effect.Anims=            ; 动画列表 , 需要注册
Effect.UnitType=         ; 单位种类
Effect.Owner=            ; 作战方归属
Effect.Money=            ; 整数型,金钱数量

[SOMETECHNO]             ; 任意单位
ExtrasType=              ; 额外属性列表
```
## 2.1额外属性-建造前提
```ini
[SOMEEXTRASTYPES]
ExtrasType=Prerequisite  ; 声明这个额外属性类型为建造前提

;建造前提的实现逻辑
Prerequisite.Condition=  ;ALL(兼容原版逻辑)|ONLY(直接接管原版和Ares的逻辑)|OR(达成任意一个即可,包括原版逻辑)

;效果定义为单位的建造条件
Effect.Technos=          ; 单位列表
Effect.Money=            ; 整数型,金钱数量
...
```
